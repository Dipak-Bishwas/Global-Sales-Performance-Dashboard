# Nova Retail Sales Performance Dashboard

## Overview
The **Nova Retail Sales Performance Dashboard** is an interactive Excel dashboard designed to analyze company sales, customer behavior, and product performance. The project provides business insights through KPI cards, charts, and dynamic filters for efficient decision-making.

---

## Key Features
- KPI Cards for:
  - Total Sales
  - Total Profit
  - Total Customers
  - Total Categories
  - Country Dealing

- Interactive Dashboard Visuals:
  - Sales Trend Analysis
  - Gender-wise Sales Analysis
  - Category Contribution
  - Country & Continent Segmentation
  - Weekday Sales Analysis
  - Product Performance Insights

- Dynamic Filters & Slicers:
  - Continent Filter
  - Category Filter
  - Customer-based Filtering
